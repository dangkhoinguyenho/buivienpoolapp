# Bui Vien Pool – Register & Manager

Pool hall point-of-sale app (KiotViet replacement): table timers, drinks/snacks, checkout (cash/card/Zelle), live sync via Firebase, owner reports.

- `register.html` – counter app (iPad/iPhone)
- `manager.html` – owner app (reports, menu, prices, sync)
- `guide.html` – setup & user guide
- `source/` – source files; `python3 source/build.py` rebuilds the pages
