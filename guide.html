Overview

There are two apps that share the same data in real time:

  • Register (register.html) runs on the counter iPads and iPhones. Staff use it to open tables, run timers, add drinks and snacks, switch tables, check out, and cancel bills.
  • Manager (manager.html) runs on the owner's phone or PC. It shows live tables, notifications, reports by cash, card and Zelle, the menu, prices, billing rules, and backups.

Hosting and sync both use free plans: GitHub Pages holds the app and Firebase holds the shared data.

One-time setup (about 30 minutes)

Step 1: Put the app online (GitHub Pages)

  1. Sign in at github.com and click New repository. Name it poolhall and set it to Public, then click Create repository.
  2. On the new repository page, click uploading an existing file. Drag in every file from the PoolHall-App folder (not the folder itself), then click Commit changes.
  3. Go to Settings → Pages. Under Build and deployment → Branch, choose main and / (root), then click Save.
  4. Wait 1–2 minutes and refresh. The page shows your link, like https://YOURNAME.github.io/poolhall/. Open it and you should see the Register and Manager buttons.
The files contain no store data and no passwords, so a public repository is safe.

Step 2: Turn on live sync (Firebase)

  1. Go to console.firebase.google.com, click Create a project, and name it (e.g. poolhall). You can turn Google Analytics off. Click Create.
  2. In the left menu, open Build → Firestore Database → Create database. Pick a location near you (e.g. us-west2), choose Start in production mode, and click Create.
  3. Open the Rules tab. Delete what's there, paste the rules shown in the Manager under Sync & backup → Firestore security rules (there's a Copy button), and click Publish.
  4. Click the ⚙️ gear → Project settings. Under Your apps, click the </> (Web) icon, enter any nickname, and click Register app. Skip Hosting. Firebase shows code beginning const firebaseConfig = {. Copy that whole block.
  5. Open …/poolhall/manager.html on the owner's PC or phone and go to Sync & backup. Paste the code into the box, keep "Upload this device's menu & settings" checked, and tap Create new store.
  6. The dot at the top turns green and says Synced ✅.

Step 3: Install on each device

  1. In Manager → Sync & backup, copy the Register link and send it to each counter iPad or iPhone (text or email).
  2. On each device, open the link in Safari, then tap Share ⬆ → Add to Home Screen. It now opens like a normal app.
  3. Open the Manager link only on the owner's devices. Anyone with the Manager link has full control, so don't share it. You can also set a Manager PIN under Manager → Store.
You only open the link once per device. After that, the home-screen icon remembers the store.

Step 4: Set up your store

  • Store: name, address and phone for receipts, and when the business day ends (default 4 AM, so late-night games count for the right day).
  • Tables & prices: Pool $15/hr, 3 Balls $10/hr, 4 Balls $4/hr per person. You can rename, add or remove tables.
  • Menu: Drink $1–$5 and Snack $1–$5 are set up already. You can change prices or add items.
  • Billing rules: by default the total rounds to the nearest $1 (.50 and up rounds up). Use the Try it box to see what a customer pays before changing anything.
Do a 2–3 night trial alongside KiotViet before its subscription ends.

Daily use (Register)

Home screenWhite = free. Blue = playing. Orange = paused. Each card shows the timer and the amount so far.
Open a tableTap a free table, then the big ▶ Pool / 3 Balls button. Other choices are Practice ½ (half price) and, on 3 Balls tables, 4 Balls. You stay on the table so you can add drinks right away.

The table screen

Add drinks / snacksTap the $ buttons. Items go into the yellow Selected – not added yet box first, so mis-taps are easy to fix: use − / + for quantity or ✕ to remove. Tap ✎ to write who it's for. Then tap Add to table.
Other $ amount＋ Other $ lets you type any name and price.
Change price / noteTap any line on the bill:
  • Drinks and snacks: change the quantity, price, % off or Free, or add a note. If a note applies to only 1 of 2 drinks, the app splits the line.
  • Timers: change the rate (e.g. $10 → $8/hr), % off (50% = practice), or minutes played, or add a note.
Pause (break)❚❚ Pause stops the clock and the screen turns orange. ▶ Resume continues. The break is not charged.
Cut time / new timer＋ Add timer lets you pick Pool, 3 Balls, Practice ½ or 4 Balls. "Stop the current timer" is checked by default. Add as many timers as you need, and they all stay on the bill.
Switch table⇄ Switch table (on the table or the home screen). Pick the new table. Timers move exactly as they are, so a pool timer stays pool. Add a 3 Balls timer yourself if needed. Picking a table that's already playing merges the two bills.
More ⋯Table note, and Cancel table (opened by mistake or the guest left right away). Nothing is charged, but the owner sees it.

4 Balls ($4/hr per person)

  • It starts with 1 player. Tap ＋ Player for each new player, who gets their own timer from that moment.
  • Tap a player's timer to type their name. When someone leaves, tap their timer and tap ■ Stop timer.

Checkout

  1. Tap Checkout. The bill freezes at that moment.
  2. Optional: tap a discount chip (10/20/50%, or $ / %…), or ✎ Change total to type the final price.
  3. Tap how the customer paid: 💵 Cash, 💳 Card (after running it in the Chase app) or ⚡ Zelle (after seeing the transfer). Split… is for mixed payments.
  4. Check that the colored button says the right method (e.g. "✓ Paid by CARD · $15.00"), then tap it.
Picked the wrong method? Go to Bills, tap the bill, and tap Change payment. To cancel a paid bill, use Cancel bill (a reason is required, and the owner is notified).

Updating the app later

  1. Ask Claude for the change and download the new PoolHall-App files.
  2. On GitHub, open your poolhall repository, then Add file → Upload files. Drag in the new files (they replace the old ones) and click Commit changes.
  3. Within a few minutes, close and reopen the app on each device. All tables, bills and settings stay, because they live in Firebase, not in the files.

Problems?

Dot says "Offline – will sync"The Wi-Fi dropped. Keep working, and everything syncs when it's back.
Dot says "This device only"That device isn't connected. Open the Register link from Manager → Sync again.
"Sync error … permission"The Firestore rules weren't published. Redo Step 2.3.
A table I had open closed by itselfSomeone checked it out or moved it on another device. The pop-up says so.
PrintingReceipts print to any AirPrint printer from the receipt screen (🖨 Print).
CostFree. Firebase's free plan allows 50,000 reads and 20,000 writes per day, far more than one pool hall uses.
