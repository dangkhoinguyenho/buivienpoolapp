Overview

There are two apps that share the same data in real time:

  • Register (register.html) runs on the counter iPads and iPhones. Staff use it to open tables, run timers, add drinks and snacks, switch tables, check out, and cancel bills.
  • Manager (manager.html) runs on the owner's phone or PC. It shows live tables, notifications, reports by cash, card and Zelle, the menu, prices, billing rules, and backups.

Hosting and sync both use free plans: GitHub Pages holds the app and Firebase holds the shared data.

Setup (already done)

The app is online at dangkhoinguyenho.github.io/buivienpoolapp, and live sync and sign-in run on Firebase (project buivienpool, Google account dangkhoinguyenho@gmail.com, free Spark plan).

Register loginUsername register. The owner signs in once on each store iPad, and it stays signed in. Staff never need the password.
Manager loginUsername manager. Owner only, and it opens the Manager.

Install on a store iPad / iPhone

  1. Open dangkhoinguyenho.github.io/buivienpoolapp/register.html in Safari.
  2. Sign in with register and the Register password.
  3. Tap Share ⬆ → Add to Home Screen. It now opens like a normal app and stays signed in.

For the owner's phone or PC, do the same with …/manager.html and the manager login.

If someone who knows the Register password leaves: Manager → Logins & backup → Change Register password. Every iPad is signed out within about an hour, then sign them in again with the new password.

Step 4: Set up your store

  • Store: name, address and phone for receipts, and when the business day ends (default 4 AM, so late-night games count for the right day).
  • Tables & prices: Pool $15/hr, 3 Balls $10/hr, 4 Balls $4/hr per person. You can rename, add or remove tables.
  • Menu: Drink $1–$5 and Snack $1–$5 are set up already. You can change prices or add items.
  • Billing rules: by default the total rounds to the nearest $1 (.50 and up rounds up). Use the Try it box to see what a customer pays before changing anything.

Add drinks / snacksTap the $ buttons. Items go into the yellow Selected – not added yet box first, so mis-taps are easy to fix: use − / + for quantity or ✕ to remove. Tap ✎ to write who it's for. Then tap Add to table.
Other $ amount＋ Other $ lets you type any name and price.
Change price / noteTap any line on the bill:
  • Drinks and snacks: change the quantity, price, % off or Free, or add a note. If a note applies to only 1 of 2 drinks, the app splits the line.
  • Timers: change the rate (e.g. $10 → $8/hr), % off (50% = practice), or minutes played, or add a note.
Pause (break)❚❚ Pause stops the clock and the screen turns orange. ▶ Resume continues. The break is not charged.
Cut time / new timer＋ Add timer lets you pick Pool, 3 Balls, Practice ½ or 4 Balls. "Stop the current timer" is checked by default. Add as many timers as you need, and they all stay on the bill.
Switch table⇄ Switch table (on the table or the home screen). Pick the new table. Timers move exactly as they are, so a pool timer stays pool. Add a 3 Balls timer yourself if needed. Picking a table that's already playing merges the two bills.
More ⋯Table note, and Cancel table (opened by mistake or the guest left right away). Nothing is charged, but the owner sees it.

Checkout

{{img:checkout}}
  1. Tap Checkout. The bill freezes at that moment.
  2. Optional: tap a discount chip (10/20/50%, or $ / %…), or ✎ Change total to type the final price.
  3. Tap how the customer paid: 💵 Cash, 💳 Card (after running it in the Chase app) or ⚡ Zelle (after seeing the transfer). Split… is for mixed payments.
  4. Check that the colored button says the right method (e.g. "✓ Paid by CARD · $15.00"), then tap it.
Picked the wrong method? Go to Bills, tap the bill, and tap Change payment. To cancel a paid bill, use Cancel bill (a reason is required, and the owner is notified).

Updating the app later

  1. Ask Claude for the change. Claude pushes it to the buivienpoolapp repository on GitHub.
  2. Within a few minutes, close and reopen the app on each device. All tables, bills and settings stay, because they live in Firebase, not in the files.
